# 校园论坛系统

一个前后端分离的校园交流社区项目。

用户可以注册、登录、发布帖子、浏览与搜索内容、发表评论、点赞、收藏，以及维护个人资料；管理员可以管理用户、帖子、评论和论坛板块。

## 技术栈

- 前端：Vue 3、Vue Router、Axios、Vite
- 后端：Python、Flask、SQLAlchemy
- 数据库：MySQL
- 身份认证：JWT

## 核心功能

### 普通用户

- 注册与登录
- 查看、搜索、筛选和分页浏览帖子
- 发布、编辑和删除自己的帖子
- 评论帖子
- 点赞与收藏帖子
- 查看和修改个人资料
- 修改密码

### 管理员

- 封禁和恢复用户
- 隐藏和恢复帖子
- 隐藏和恢复评论
- 查看、创建、停用和恢复论坛板块
