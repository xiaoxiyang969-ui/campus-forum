# 校园论坛系统需求说明

## 1. 项目目标

开发一个前后端分离的校园交流社区，为校园用户提供信息发布、内容交流和社区互动功能。

## 2. 用户角色

### 游客

- 注册账号
- 登录系统
- 浏览板块
- 查看和搜索帖子

### 普通用户

- 修改个人资料
- 发布帖子
- 修改和删除自己的帖子
- 发表评论
- 点赞帖子
- 收藏帖子

### 管理员

- 管理论坛板块
- 管理用户状态
- 隐藏违规帖子
- 隐藏违规评论

## 3. 核心功能

- 用户注册与登录
- 帖子的发布、查看、修改和删除
- 帖子分类与关键词搜索
- 评论
- 点赞与收藏
- 个人中心
- 管理员后台

## 4. 初始板块

- 校园生活
- 学习交流
- 失物招领
- 二手交易
- 社团活动

## 5. 后续增强功能

- 图片上传
- 评论回复
- 消息通知
- 举报与审核
- 热门帖子排行
- Redis 缓存
- Docker 部署
